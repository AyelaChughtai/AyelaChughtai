## Featured Work

**Linear Recoverability in CLIP**
Investigated whether visual concepts of graded complexity are linearly recoverable from frozen CLIP (ViT-B-32) embeddings using linear and MLP probes across DTD, ImageNet, CLEVR, and ARO benchmarks. Introduced intrinsic dimensionality estimation (TwoNN), silhouette scores, linear CKA, and residual decomposition for additivity tests. Found that probe accuracy, intrinsic dimensionality, and cluster separability all degrade along the texture → object → compositional → spatial-relation complexity gradient.
[Repository](https://github.com/AyelaChughtai/clip-linearity-mapping)

**Gender Bias in LLMs via Mechanistic Interpretability**
Designed SAE feature-level interventions to surgically reduce gender stereotyping in GPT-2 small. Discovered occupation-conditional gender features (F4077, F23772, F837) at `blocks.11.hook_resid_pre` using the `gpt2-small-res-jb` SAE and compared head-level ablation against feature-level clamping on a unified evaluation protocol (WikiText-103 PPL, LAMBADA, BLiMP, Winogender, CrowS-Pairs). Key finding: head-level entanglement is breakable at the feature level, but identified features don't generalize beyond narrow occupation clusters.
[Repository](https://github.com/AyelaChughtai/mechinterp-gender-bias)

**Cyclone Shelter Allocation — Bangladesh**
Equitable, robust cyclone shelter access under uncertainty via geospatial optimization, coverage models, and robust optimization.
[Repository](https://github.com/AyelaChughtai/CycloneShelterOptimization)

**Bike Lane Obstruction Detector**
Detection of bike-lane obstructions from street imagery using YOLOv8, ViT, SegFormer, and U-Net with model comparison and error analysis.
[Repository](https://github.com/AyelaChughtai/CarInBikeLane)

**Accident Prediction + Policy Design — Miami-Dade**
Predictive modeling of severe crash risk paired with prescriptive optimization for resource deployment and mitigation policy.
[Repository](https://github.com/AyelaChughtai/OptimizationBasedAccidentPredictionandPolicyDesign)
